## 🛠️ **SETUP INSTRUCTIONS**

### **1. Create the folder structure:**
```bash
mkdir -p ai-specialist-learning/{claude-hub,ai-tools-guide,tech-dictionary,learning-resources,ai-updates}
cd ai-specialist-learning
```

### **2. Copy template files** from each module's folder

### **3. Install VS Code Extensions** (recommended):
- **Markdown Preview Enhanced** - Better markdown rendering
- **Markdown All in One** - TOC generation
- **Peacock** - Color-code your folders (use your yellow accent!)

### **4. Set VS Code Theme:**
- Recommended: One Dark Pro or Dracula (matches your dark aesthetic)
- Font: Use your preferred mono font (JetBrains Mono, Fira Code, etc.)
